# 공지 읽기 측정 도구

[index.html](index.html)을 브라우저에서 열면 기존 방식과 Unimate를 비교할 수 있다. 참가자마다 공지 두 건을 읽고 마감일과 신청 방법을 답한다. 참가자 순번이 홀수인지 짝수인지에 따라 각 공지에 배정하는 방식이 번갈아 바뀐다.

Unimate 쪽 시도는 배포된 앱(`https://unimate-campus.vercel.app`)의 방문객 공지 화면(`/visit/notices`)을 참가자 언어로 연다. 로그인이 필요 없고, 기타 언어를 고른 참가자는 영어 화면을 쓴다. 앱 주소는 설정에서 바꿀 수 있다.

시도마다 시작·멈춤 버튼으로 걸린 시간을 재고, 마감일 정답 여부, 신청 방법 정답 여부, 불안도(1~5)를 입력한다. 시간을 멈추고 세 항목을 모두 입력해야 저장할 수 있다. 측정 장소는 참가자를 시작할 때 입력하며 그 참가자의 기록에 함께 저장된다.

요약의 정답 집계는 두 항목을 모두 맞힌 경우만 센다. 기록이 없으면 평균은 `—`로 표시한다. 입력 기록은 브라우저의 로컬 저장소에 보관되고, 저장소를 쓸 수 없으면 경고를 보여 준다. 저장된 데이터가 깨져 있으면 올바른 항목만 불러온다.

CSV 저장 버튼은 `results.csv`를 내려받는다. 파일은 UTF-8(BOM 포함)이라 엑셀에서 한글이 깨지지 않으며, 모든 칸을 따옴표로 감싸고 줄바꿈은 공백으로 바꾼다. `=`, `+`, `-`, `@`로 시작하는 문자열 앞에는 `'`를 붙인다.
